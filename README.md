# Obsidian config

My Obsidian settings: themes, CSS snippets, hotkeys, and plugin settings.

## Use it
1. Copy the contents of this repo into your vault's `.obsidian/` folder.
2. Open Obsidian → Settings → Community plugins → turn on community plugins.
3. Install the plugins listed in `community-plugins.json` (settings are already here, only the plugin code is missing).
4. Restart Obsidian.

## Task setup (TaskNotes)
- New tasks go to `Tasks/Open`, finished tasks move to `Tasks/Done` automatically.
- `Alt+T` creates a new task.
